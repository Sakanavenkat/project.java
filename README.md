Tic Tac Toe Game :

A simple console-based 3x3 Tic Tac Toe game built using Java. Two players (X and O) take turns marking spaces in a 3×3 grid. The player who succeeds in placing three of their marks in a horizontal, vertical, or diagonal row wins the game.

---

Features :

- Two-player support (X vs O)
- Easy-to-use number-based input system
- Real-time board updates after each move
- Input validation:
- Invalid number inputs
- Already taken slots
- Win and draw detection
